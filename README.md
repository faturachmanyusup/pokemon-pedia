# Pokemon Pedia

This is a [Next.js](https://nextjs.org/) project built with **React 18** and **TypeScript (strict mode)**.

## Tech Stack

- **React 18.2.0** - Latest React with concurrent features
- **TypeScript 5.2.0** - Strict mode enabled for maximum type safety
- **Next.js 13.5.0** - React framework with SSR/SSG support
- **Emotion** - CSS-in-JS styling solution
- **Apollo Client** - GraphQL client
- **Jest** - Testing framework

## Preparations

```bash
npm i
# or
yarn install
```

## Run dev server

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Available Routes

- /pokemon
- /pokemon/[ pokemonName ]
- /my-pokemon
- /my-pokemon/[ named pokemon ]

## Type Checking

```bash
npm run type-check
# or
yarn type-check
```

## Run test

```bash
npm run test
# or
yarn test
```

## Build for Production

```bash
npm run build
# or
yarn build
```

Note: To see actual scores of lighthouse please use prod env instead of dev
